# SurvivalGame
# 3D戦略型領地島支配サバイバルゲーム（SurvivalGame）

## 1. 概要
- **ジャンル:** サバイバル系 / 3D戦略型領地支配
- **プレイ人数:** 多数（サーバー仕様依存）
- **初期所持品:** 石 ×1
- **マップ規模:** 1024 × 1024（約1,048,576エリア）

## 3. プレイヤーシステム・操作方法

### ステータス
- **ヘルス:** 100
- **水分値:** 100
- **飢餓値:** 100
- **インベントリ:** 最大15スタック（資源・食料: 1スタック1000個 / 道具・武器: 1スタック1個）

### 操作方法
- **移動:** `WASD` または `矢印キー`
- **早歩き:** `Shift` + 移動キー
- **アイテム拾得:** `F`
- **攻撃 / 採取:** `マウス左クリック`
- **インベントリ:** `Tab`

## 5. 食料・料理システム

### 基本食料
- **果物・野菜:** ベリー, スイカ, トマト, トウモロコシ, キノコ, じゃがいも
- **水産・畜産:** 生魚, 焼き魚, エビ, 牛乳, チーズ, 生卵, ゆで卵, 生鶏肉, 生牛肉, 調理された鶏肉, 調理された牛肉

### 食事バフのルール
- 食事バフは**最大2種類まで**同時適用可能。
- 同種の料理を食べると効果時間が延長。
- 3種類目を食べると**最も古いバフが消去**され、新しいバフが付与される。

## 6. 建築・設備・罠

### コア・家具・設備
- **ツールボックス:** `木×400` `縄×30` `石×50`
  - 半径100×100の領域の所有権を確立。建築物の耐久値を1分ごとに全回復。他者の建築を防止。
- **焚火（耐久 50）:** `木×20` `石×30`（簡易調理）
- **かまど（耐久 5000）:** `石×400` `木×400` `粘土×25`（鉱石加工）
- **調理場（耐久 5000）:** `木×350` `石×200` `鉄の破片×100` `縄×3`（加工食品調理）
- **作業台（耐久 5000）:** `木×200` `石×50` `縄×3`（鉄製品・武器製作）
- **貯水場（耐久 5000）:** `高級木材×150` `葉×25` `縄×8`（雨水貯蔵）
